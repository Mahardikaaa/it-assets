Import assets from CSV or Excel
Pick a .csv or .xlsx file with a header row in the first line. Columns read: Asset tag, Device name, Category, Brand / model, Serial number, Assigned to, Location / department, Status, Purchase date, Warranty ends. Asset tag and Device name are required. Dates can be 2025-03-01 or 01/03/2025 (day first).
